# بطاريتي — مراقبة بطارية المنزل

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) بواجهة عربية بسيطة لمراقبة بطارية LiFePO4 منزلية
يديرها نظام JBD، عبر Bluetooth Low Energy محليًا. **للقراءة والمراقبة فقط.**

> **حالة الاتصال الحقيقي: لم يُختبر بعد على البطارية.** تحليل البروتوكول مُختبر على إطارات
> حقيقية ملتقطة من أجهزة مشابهة (من مشروع مفتوح المصدر)، لكن طريقة نقله عبر البلوتوث في
> بطاريتك تحتاج تأكيدًا بأداة «فحص الاتصال» داخل التطبيق. التفاصيل في [docs/FEATURES.md](docs/FEATURES.md).

## البناء والتثبيت

المتطلبات: JDK 17 أو أحدث، وAndroid SDK (المنصة 35).

```bash
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew :core:test :app:testDebugUnitTest   # الاختبارات
./gradlew :app:assembleDebug                  # ملف APK
```

الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`. انقله إلى الهاتف وثبّته (اسمح بالتثبيت
من مصادر غير معروفة). كل دفع إلى GitHub يبني الملف أيضًا ويرفعه ضمن Artifacts في تبويب Actions.

ملاحظة: نسخة debug موقّعة بمفتاح محلي يختلف من جهاز بناء لآخر، فقد تحتاج حذف النسخة القديمة قبل تثبيت نسخة بُنيت على جهاز آخر.

## أول استخدام

1. أغلق تطبيق JBD الأصلي تمامًا (البطارية تقبل اتصالًا واحدًا).
2. افتح «بطاريتي» ← «اتصل بالبطارية» ← امنح إذن البلوتوث ← «ابحث».
3. اضغط **«فحص الاتصال»** على بطاريتك وشارك التقرير (المعرّفات محجوبة افتراضيًا).
4. إن قال التقرير إن الجهاز يردّ، اضغط «اتصال».

## بنية الكود

| المسار | المحتوى |
|---|---|
| `core/` | Kotlin صِرف بلا أندرويد: البروتوكولان، تجميع الحزم، CRC، الحسابات، المحاكي، CSV — مع اختباراته |
| `app/.../ble/` | البلوتوث: البحث، جلسة GATT، الاستطلاع وإعادة الاتصال، الفحص التشخيصي |
| `app/.../data/` | الإعدادات، السجل المحلي (SQLite)، والفصل بين المصدر الحقيقي والمحاكي |
| `app/.../ui/` | الشاشات (Compose، RTL، فاتح/داكن) |

## الأمان

- كل كتابة على البلوتوث تمر عبر `ReadRequests.isAllowedRead` التي لا تقبل إلا ثلاثة إطارات قراءة محددة. لا يوجد في الكود أي باني لأوامر التعديل.
- لا يوجد إذن `INTERNET` في التطبيق.
